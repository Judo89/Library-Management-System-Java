# Library Management System (Java)

A Java console-based application for managing a library system.  
The project demonstrates core Java concepts including OOP, Data Structures, File Handling, and clean business logic.

---

## 🚀 Features

- Add new books with unique IDs
- Prevent duplicate book IDs
- Borrow and return books
- Prevent borrowing unavailable books
- Prevent returning books that were not borrowed
- Search books by title (partial search supported)
- Persistent storage using file handling
- Borrow/Return history logging
- Optimized data access using HashMap

---

## 🛠 Technologies Used

- Java
- Object-Oriented Programming (OOP)
- Data Structures (ArrayList, HashMap)
- File Handling (BufferedReader / BufferedWriter)
- Java Collections
- Basic Logging

---

---

## 📌 How It Works

1. The system loads books from a file at startup.
2. Users can add, borrow, return, and search for books.
3. All changes are saved automatically to files.
4. Borrow and return actions are logged with timestamps.
5. The system validates all operations to prevent logical errors.

---

## ▶ How to Run

1. Clone the repository
2. Open the project in IntelliJ IDEA or any Java IDE
3. Run `Main.java`
4. Use the console menu to interact with the system
